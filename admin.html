Falta conectar la base de datos ✿

El panel necesita una base de datos en línea (gratis) para guardar productos y pedidos.

  1. Crea un proyecto gratis en supabase.com.
  2. En SQL Editor corre supabase/schema.sql (y si quieres supabase/seed.sql).
  3. En Authentication → Users crea la cuenta de la dueña.
  4. Copia la Project URL y la publishable key en js/config.js.

Los pasos detallados están en el README del proyecto 💕
